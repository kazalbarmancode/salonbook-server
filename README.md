# SalonBook — Backend API

SalonBook is a Beauty & Salon Appointment Booking Platform. This repository contains the backend API developed using **Node.js**, **Express.js**, and **MongoDB**. The backend manages salon services, customer appointments, user authentication, administrator operations, and Stripe payments.

## Live Links

- **Frontend:** [https://solonbook-client-obo9.vercel.app](https://solonbook-client-obo9.vercel.app)
- **Backend API:** [https://salonbook-server-rbcg.vercel.app](https://salonbook-server-rbcg.vercel.app)

## Features

- RESTful API using Express.js.
- MongoDB database integration.
- Better Auth JWT authentication.
- Role-based authorization for administrators.
- Customer appointment booking.
- Appointment cancellation and rescheduling.
- Admin appointment management.
- Service creation, updating, activation, and deletion.
- User blocking and unblocking.
- Stripe Checkout integration.
- Stripe webhook signature verification.
- Payment transaction storage.
- BDT to USD currency conversion.
- Protected API endpoints.
- Customer appointment ownership verification.

## Technology Stack

- **Runtime & Framework:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication & Tokens:** Better Auth, JSON Web Token (JWT), JOSE
- **Payments:** Stripe
- **Deployment:** Vercel
